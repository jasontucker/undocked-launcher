Add Remote Server

On the remote host, add to /etc/docker/daemon.json:
{"hosts": ["unix:///var/run/docker.sock", "tcp://0.0.0.0:2375"]}
Then restart Docker: sudo systemctl restart docker
SSH requires a key from this server to the remote host.
Run on Unraid: ssh-keygen -t ed25519
Then: ssh-copy-id user@remote-host
