Cloudflare

Tailscale

Found at tailscale.com/admin/dns under your tailnet name

Each container's Tailscale URL is built from its Tailscale Hostname set in the Unraid Docker manager + this domain.
e.g. hostname movies → https://movies.my-tailnet.ts.net

Add this Docker label to map the hostname automatically:
homepage.tailscale.hostname=movies
(falls back to the container name if the label is absent)

Other per-container Docker labels:
homepage.name=Radarr
homepage.description=Movie Manager
homepage.group=Media
homepage.icon=https://example.com/icon.png
homepage.cloudflare.url=https://radarr.mydomain.com
homepage.tailscale.url=https://movies.my-tailnet.ts.net (full override)
homepage.direct.url=http://192.168.1.100:7878
homepage.enable=false (hide from dashboard)
